# BVB development

Read `CLOUD.md` for setup, preview and validation commands. This repository works
from its checkout; do not introduce paths to a personal PC.

Use `bash scripts/setup.sh` once, then `npm run check` and `npm test`.
Preview: `npm run dev -- --port 8080`. Runtime data and screenshots are ignored.
Use synthetic requests only. Never copy operator keys, customer uploads or
private research into Git. Preserve unrelated changes and image provenance.
This site is public; keep private data and other brands out of this repository.

Save meaningful work in Git and use a separate branch for website changes.
Before merging or deploying website content, obtain the user authorization
required by the task. Cloud setup is development, not production hosting.
Generated product visuals are not evidence of stock or successful printing.
